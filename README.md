# work-os · 个人工作进度管理看板

自然语言录入的个人工作管理工具：对着输入框"说话"，DeepSeek 解析成任务/日志，确认后入库；首页 = 数据统计条 + 周视图主视图，另有月视图与 AI 周报。

## 功能

- **首页数据条**：本周进度（百分比+像素数字）、漂流瓶（超期+待认领）、待启动/进行中/已完成计数——后四项点开看任务列表
- **周视图主视图**：周一~周日七列，父子任务按日落列（同日父子合并为一卡）；拖拽改日期（父改截止、子改计划）；卡片 ✓ 快速完成；周导航可回看历史周；「拖欠」横条滚存过期任务；「未排期」栏收容无日期任务（仅本周显示）
- **自动分列口径**：待启动 = 未完结且(日期>今天或无日期)；进行中 = 未完结且日期≤今天（含超期标红）；已完成
- **自然语言录入**：口语描述 → DeepSeek 解析 → 确认卡片（可改项目/截止/子任务）→ 入库；"先…再…"自动拆子任务
- **补记闭环**："今天/昨天/上周五完成了 XX" 自动生成任务并把日志、完成时间记到对应日期
- **月视图**：工作量热力（蓝→黄→橙→红预警色阶）
- **AI 周报**：DeepSeek 基于本周完成+日志+未完成任务生成简版/详版，故障自动回退模板
- **待认领区**：挂不上项目的解析结果暂存，可认领/恢复

## 关键口径

- **状态集**：待启动 / 进行中 / 已完成（v8 起简化，历史"待确认审核/待办事项"已迁移转换）
- **超期**：父任务看 deadline、子任务看 planned_date，过期且未完成即超期
- **本周进度**：分母 = deadline∈本周的父任务 + planned_date∈本周的子任务；分子 = 其中「已完成」
- **下周计划（周报）**：未完成任务平移，不按日期筛选

## 技术栈

Next.js 14（App Router）· TypeScript · Tailwind（品牌蓝 #3E81F6）· better-sqlite3（WAL）· DeepSeek API · dnd-kit · Vitest

## 本地开发

```bash
cp .env.example .env   # 填入 DEEPSEEK_API_KEY
npm ci
npm run dev            # http://localhost:3000
```

```bash
npm test               # Vitest（口径纯函数 + 落库 + 周报聚合）
npm run lint
npm run build
```

数据存于 `data/work-os.db`（SQLite，首次启动自动建表+迁移+播种预置项目）。

## 环境变量

见 `.env.example`：`DEEPSEEK_API_KEY`（必填）、`ACCESS_PASSWORD`（公网访问口令，留空关闭密码门）、`SEED_PROJECTS`（首次启动预置项目）。

## 部署

服务器直跑 `next start`（:3000，IP 直连访问）。详细发布步骤见 `AGENTS.md` 部署章节。

## 分支与协作

`main` 为保护分支，功能开发走 `feature/xxx` / `fix/xxx`，本地验收（localhost 预览 + `npm test` 全绿）通过后合并。变更历史见 `CHANGELOG.md`。
